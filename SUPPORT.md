# Support

CivVIToolkit is currently a Preview project.

For trainer issues, include the exact Civilization VI store/renderer/build and the copied runtime diagnostics. Trainer write support is build-specific and unknown GameCore fingerprints intentionally fail closed.

The currently verified research target is Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` with GameCore SHA-256 `324c51e9ea3531758842e16c69e6cddbefbb226c5b675c3d6e60111646c2e98c`.

Do not report multiplayer or anti-cheat bypass requests; those are outside the project scope.
