# CivVIToolkit v0.3.2 Preview

This acceptance build focuses on the three issues found during real v0.3.1 testing.

## Trainer attachment

- Fixes the trainer remaining permanently in Runtime Error when `Player::Manager` is temporarily null while a Gathering Storm match is still initializing.
- Automatically retries exact-profile attachment while the game process and GameCore are loaded but the Trainer is not ready yet.
- Keeps the exact Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) GameCore SHA-256, 13 AoB checks, and pointer-chain fail-closed boundary. Unsupported builds still reject writes.

## UI and high DPI

- Moves trainer categories into a horizontal category bar so the feature list can use the full content width.
- Tightens trainer row columns to prevent NumberBox, ToggleSwitch, and status text overlap.
- Sizes the compact window using `XamlRoot.RasterizationScale`, fixing the physical-pixel/effective-pixel mismatch at 150%/200% display scaling.
- Simplifies compact rows to feature/status, shortcut, and action controls for better high-DPI usability.

## Live language switching

- Language changes now update the MRT Core language, current Culture, ResourceLoader, and visible UI immediately without restarting the app.
- Runtime relocalization covers the shell, navigation, Home, Trainer, Diagnostics, Settings, and Compact Trainer.
- Fixes the raw `!Settings_RestartInfo...!` placeholders shown by the old restart prompt.

This remains a Preview acceptance build; GitHub publication stays disabled.
