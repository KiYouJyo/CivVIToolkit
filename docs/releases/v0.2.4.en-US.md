# CivVIToolkit v0.2.4

This release continues refining trainer acceptance UX, focusing on shortcut-badge stability and configurable value actions.

## Changes

- Fix shortcut badge dimensions and placement so they no longer jump during polling refreshes.
- Rebuild the trainer list only when visible trainer state actually changes instead of recreating ListView items on every process poll.
- Add numeric input boxes for Add Gold and Add Influence.
- Keep configured values for the current app session; both row activation and global hotkeys use the current input value.
- Accept positive integer values from 1 to 8,000,000 while retaining the fixed-point overflow guard in the trainer core.
- Correct the app wiring so it actually uses the stability-oriented trainer engine introduced for v0.2.3.

## Acceptance focus

1. Leave the trainer page open for several minutes and confirm shortcut badges stay visually fixed while background checks run.
2. Change the Add Gold and Add Influence values, then execute each through both row activation and its hotkey.
3. Enable several continuous trainer features together and continue validating the v0.2.3 stability scheduler.
