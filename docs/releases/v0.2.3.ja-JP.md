# CivVIToolkit v0.2.3 Preview

## 今回の重点：複数機能同時使用時の安定性

- 安定性スケジューラを導入し、複数の Toggle を同一サイクルで一括書き込みせず、機能ごとに順番・間隔を分けて直列実行します。
- live Unit コレクションの chunk 範囲を `+0x98/+0xA0` に修正し、複数のユニット系機能を同時に有効化した際の無効オブジェクト書き込みを防ぎます。
- GameCore のリモート呼び出しは研究・社会制度・生産・資源など必要な機能だけで作成し、クールダウンと同一ターゲットへの連続呼び出し抑制を追加しました。
- 1ターン研究 / 社会制度は同じ対象に高頻度で再実行しません。
- 1ターン生産は1サイクルにつき1都市だけ処理し、生産キュー更新中の再入を避けます。
- AI の研究 / 社会制度 / 生産 / 資源系は AI プレイヤーを順番に処理し、1サイクルのリモートスレッド数と書き込み量を抑えます。
- Unit / City コレクションは書き込み前にスナップショット化し、走査中のコレクション変化による無効アドレスを避けます。
- Int32 の直接書き込みは値が変化した場合のみ行い、不要な高頻度メモリ書き込みを削減します。
- ある機能が失敗した場合、その機能だけをバックグラウンド実行から外し、他の有効機能は継続します。
- Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) の SHA-256 と 13 個の AoB アンカーによるゲートは維持します。

## 検証推奨

まず `Num 1 + Num 2 + Num 6 + Num 7 + PageDown` を同時に有効化して数分間動作確認し、その後に都市・資源・AI 機能を段階的に追加してください。リモート呼び出し系は最後に追加するのがおすすめです。
