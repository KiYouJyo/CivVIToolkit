# CivVIToolkit v0.3.1 Preview

- UrbanPlanToolbox の実際の WinUI 3 シェルを参考に、ネイティブ `TitleBar`、`NavigationView`、Mica、システムテーマリソースへ切り替え、従来の自前ナビゲーションで弱かったアニメーション・選択フィードバック・質感を改善しました。
- ホーム、診断、設定などの固定 MaxWidth を廃止し、最大化時は利用可能な幅を活用します。中～狭幅ではセッションカード、モジュールカード、診断カード、言語設定を自動的に再配置します。
- Steam / Epic、DX11 / DX12 の検出とクイック起動はホームに維持し、セーブ管理、Mod 管理、百科事典は入口のみ残します。
- 実機検証済み Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` Trainer Profile を新 UI に再接続しました。
- 22 項目、グローバルショートカット、安定化スケジューラ、ゴールド／影響力の入力値、常時最前面のコンパクト Trainer を復元しました。
- GameCore SHA と 13 個の AoB 検証が一致しない場合は fail-closed で書き込みを拒否します。

> Preview 版です。Trainer は Civilization VI のローカル・シングルプレイ専用です。
