# CivVIToolkit v0.3.5 Preview

## Fixed
- Reworked the Trainer list around stable observable view models. The 22 rows are created once; background polling now updates properties in place through `INotifyPropertyChanged` instead of periodically rebinding `ItemsSource`.
- Main Trainer and Compact Trainer share the same stable row instances, and the compact window no longer resets its list source during state refreshes.
- Added explicit Apply buttons to Add Influence and Add Gold. Enter a value and press Apply; existing global hotkeys still use the current configured value.
- Retains the v0.3.4 process/GameCore polling debounce as a second session-level stability guard.

## Retained
- All 22 single-player Trainer features, stability scheduler, and global hotkeys.
- Exact Steam / DX12 / Gathering Storm 1023995 SHA + 13 AoB fail-closed validation.
- v0.3.3 high-DPI and compact-window layout fixes.
