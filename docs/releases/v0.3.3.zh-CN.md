# CivVIToolkit v0.3.3 Preview

本次版本针对 v0.3.2 实机验收中仍然存在的修改器控件遮挡继续收束 UI。

## 修复
- 限制 WinUI `ToggleSwitch` 的布局占位宽度，避免默认模板在快捷键区域下方溢出。
- 主修改器与紧凑修改器共用同一套受约束的原生 ToggleSwitch 布局。
- 紧凑修改器改为上下两层信息布局，将功能名/状态与快捷键/操作控件分离，彻底避免横向挤压。
- 紧凑窗口逻辑宽度提高到 580 DIP，并继续按 `RasterizationScale` 转换为物理像素，适配 150% / 200% Windows 缩放。
- 金钱与影响力 NumberBox 保留独立操作区域，不与开关或快捷键共享布局空间。

## 保持不变
- Steam / DX12 / Gathering Storm 1023995 精确 Profile 与 fail-closed 校验保持不变。
- 22 项修改器、全局快捷键、稳定性调度器和实时语言切换保持启用。
- 存档管理、Mod 管理和百科仍只保留入口。
