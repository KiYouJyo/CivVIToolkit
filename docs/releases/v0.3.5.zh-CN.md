# CivVIToolkit v0.3.5 Preview

## 修复
- 修改器列表改为稳定 ViewModel：22 个条目只创建一次，后台轮询只通过 `INotifyPropertyChanged` 原位更新状态，不再周期性重绑 `ItemsSource`。
- 主修改器和紧凑修改器共享同一批稳定条目；紧凑窗口不再在状态刷新时重新设置列表数据源。
- “增加影响力”和“增加金钱”新增明确的“应用”按钮；输入数值后点击按钮即可执行，原有全局快捷键仍会读取当前输入值。
- 保留 v0.3.4 的进程/GameCore 轮询去抖逻辑，作为会话层的第二道稳定保护。

## 保留
- 22 项单机修改器、稳定性调度器和全局快捷键。
- Steam / DX12 / Gathering Storm 1023995 精确 SHA + 13 AoB fail-closed 校验。
- v0.3.3 的高 DPI / 紧凑窗口布局修复。
