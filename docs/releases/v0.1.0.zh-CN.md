本版本建立 CivVIToolkit 的第一套可安装发布基础：

- 自动识别 Steam / Epic Games 安装来源；
- 自动识别 Civilization VI 的 DX11 / DX12 运行进程；
- 提供只读 Runtime Diagnostics，用于后续建立稳定 Signature Profile；
- 建立经典 22 项单机 Trainer 的功能目录与安全 gating，尚未启用未经验证的内存特征码；
- 预留存档管理、地图与游戏信息、Mod 管理、快捷启动等工具箱模块；
- 提供简体中文、日本語、English 三语界面；
- 改用签名的 x64 MSIX 安装包，避免依赖解压后直接运行 WinUI 3 可执行文件；
- 增加一键安装 ZIP、签名验证与 SHA-256 校验。

> 当前仍为 Preview。Trainer 仅用于 Civilization VI 本地单机模式。
