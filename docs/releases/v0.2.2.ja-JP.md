# CivVIToolkit v0.2.2 Preview

このバージョンでは、実際のシングルプレイヤー中に `The game root pointer is null.` が発生し、Trainer の全項目が実行エラーになる問題を修正します。

## 修正内容

- GameContext ルートポインターをローカルプレイヤー解決の唯一の経路として扱わないように変更。
- 通常時は検証済みの GameContext → LocalPlayerId 経路を引き続き優先。
- Civilization VI が実行中に GameContext ルートを一時的にクリアした場合、当該 Build で既に実機確認済みの `Player::Manager` シングルプレイヤースロット 0 をフォールバックとして使用。
- フォールバック前に、プレイヤースロットが有効であること、および Treasury / Religion / Influence の live component ポインターがすべて存在することを確認。検証に失敗した場合は書き込みを拒否。
- 13 個の AoB アンカーと GameCore SHA-256 ロックは維持し、対応 Build の安全ゲートは緩和しない。

## 受け入れ確認

Gathering Storm のシングルプレイヤーに入った後、`game root pointer is null` によって全機能が実行エラーにならないことを確認してください。まず Num 1、Num 2、Num 5、PageUp を確認し、その後ユニット、都市、研究、社会制度、生産、AI 系機能を確認します。
