# CivVIToolkit v0.3.1 Preview

- Reworks the shell around the same native WinUI 3 approach used by UrbanPlanToolbox: `TitleBar`, `NavigationView`, Mica, and system theme resources replace the hand-painted navigation surface, improving motion, selection feedback, and material consistency.
- Removes the fixed page-wide max-width caps from Home, Diagnostics, and Settings so maximized windows use the available width. Session cards, module cards, diagnostics cards, and language controls reflow at medium and narrow widths.
- Keeps Steam / Epic and DX11 / DX12 discovery and launch controls on Home, while Save Manager, Mod Manager, and Encyclopedia remain empty entrances.
- Reconnects the live-validated Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` Trainer Profile to the redesigned UI.
- Restores all 22 trainer features, global hotkeys, staggered stability scheduler, configurable Gold / Influence actions, and the always-on-top compact trainer window.
- Keeps fail-closed safety: memory writes are rejected whenever the exact GameCore SHA or any of the 13 AoB validations do not match.

> This is still a Preview. The trainer is for local Civilization VI single-player only.
