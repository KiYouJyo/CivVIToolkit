v0.1.1 Preview は、最初の実機 Civilization VI Trainer Build 検証に重点を置いた更新です。

- Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` 向けの最初の厳密な GameCore Profile を追加；
- GameCore SHA-256 で対応 Build を厳密に固定；
- GameCore の実行時 AoB 検証とローカルプレイヤーの読み取り専用リソース Probe を追加；
- 初回実機検証で判明した Player Manager singleton と active-player slot chain の誤りを修正；
- Game Context の current-game getter、正しい Player Manager getter、および 10 個の実行時シグネチャ anchor を検証；
- Gold / Faith / Influence の raw fixed-point 値と Manager / Player / Component のアドレスを診断 JSON に追加；
- このバージョンでも Trainer の書き込みは無効のままで、読み取りチェーンとシグネチャが完全に検証された後にのみ実際の変更機能を有効化します。

> 現在も Preview です。Trainer は Civilization VI のローカル・シングルプレイ専用です。
