# CivVIToolkit v0.2.3 Preview

## 本轮重点：多功能并行稳定性

- 新增稳定性调度器：多个 Toggle 不再在同一轮里集中写入 GameCore，而是按功能轮转、限频、串行执行。
- 修正 live Unit 集合的 chunk 范围为 `+0x98/+0xA0`，避免多项单位功能同时开启时写入无效对象。
- 远程 GameCore 调用只在研究、市政、生产、资源等确实需要时创建，并增加冷却与重复目标抑制。
- 一回合研究 / 市政不会对同一目标连续高频重复调用。
- 一回合生产每轮只处理一个城市，避免在生产队列变化时连续重入 GameCore。
- AI 研究 / 市政 / 生产 / 资源类功能改为逐 AI 轮转处理，降低单轮远程线程和写入峰值。
- 单位 / 城市集合在写入前先快照，避免遍历过程中对象集合变化导致悬空地址。
- 所有直接 Int32 写入仅在值发生变化时执行，减少无意义的高频写内存。
- 单个功能运行失败时会自动退出后台调度，不再继续轰击游戏进程；其他已启用功能保持运行。
- 保留 Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) 的 SHA-256 与 13 个 AoB 锚点门禁。

## 验收建议

先同时开启 `Num 1 + Num 2 + Num 6 + Num 7 + PageDown` 运行数分钟，再逐步加入城市、资源以及 AI 功能。高风险的远程调用类功能建议最后加入。
