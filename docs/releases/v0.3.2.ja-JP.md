# CivVIToolkit v0.3.2 Preview

この受け入れビルドでは、v0.3.1 の実機テストで確認された3つの問題を重点的に修正します。

## Trainer 接続

- Gathering Storm の対局初期化中に `Player::Manager` が一時的に null になった後、Trainer が「実行エラー」のままになる問題を修正しました。
- ゲームプロセスと GameCore が読み込まれている一方で Trainer が未準備の場合、精密プロファイルへの接続を自動的に再試行します。
- Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) の正確な GameCore SHA-256、13 項目の AoB、ポインタチェーンの fail-closed 検証は維持します。未対応ビルドでは引き続き書き込みを拒否します。

## UI と高 DPI

- Trainer のカテゴリを上部の横並びカテゴリバーへ移し、機能一覧がコンテンツ幅全体を使用できるようにしました。
- NumberBox、ToggleSwitch、状態テキストが重ならないよう Trainer 行の列幅を整理しました。
- `XamlRoot.RasterizationScale` でコンパクトウィンドウの論理サイズを物理ピクセルへ換算し、150% / 200% 表示スケールでウィンドウが狭くなる問題を修正しました。
- コンパクト行を「機能名 / 状態」「ショートカット」「操作」の3列へ簡素化しました。

## 言語の即時切り替え

- 言語変更時に MRT Core 言語、現在の Culture、ResourceLoader、表示中 UI を即時更新し、アプリ再起動を不要にしました。
- シェル、ナビゲーション、ホーム、Trainer、診断、設定、コンパクト Trainer を実行時に再ローカライズします。
- 旧再起動メッセージで `!Settings_RestartInfo...!` がそのまま表示される問題を修正しました。

本バージョンは引き続き Preview の受け入れビルドで、GitHub の正式公開は無効のままです。
