CivVIToolkit v0.3.0 Preview では、Figma で設計した v2 UI を WinUI 3 に反映し、既存の実機能を新しい画面へ接続しました。

- 48 px のタイトルバー、220 px の折りたたみ可能なサイドバー、ライトテーマのキャンバスとカードを採用。
- ホーム画面に Steam / Epic Games、DX11 / DX12、PID、バージョン、パス、再スキャン、クイック起動を統合。
- 初版 22 項目の Trainer を「資源と経済 / 科学と文化 / ユニットと戦闘 / 都市と建設」に整理し、カテゴリ切替と検索に対応。
- ゲーム中に使いやすい常に手前に表示されるコンパクト Trainer ウィンドウを追加。
- プリセットと診断画面では、ユーザー操作による読み取り専用 Runtime Diagnostics を提供。
- 設定と情報画面では言語設定とバージョン表示を維持。
- セーブ管理、Mod 管理、百科は現在の計画どおり入口のみを残し、未実装データを表示しません。
- 実行時 Signature の検証が完了していない Trainer 書き込みは引き続き無効です。
- アプリ、MSIX、リリースメタデータを 0.3.0 / 0.3.0.0 に統一。

> 現在は Preview です。Trainer は Civilization VI のローカル・シングルプレイヤー専用です。
