# CivVIToolkit v0.2.1 Preview

このバージョンは、v0.2.0 の22機能一括受け入れテストで確認された「実行エラー」を構造的に修正します。

## 修正

- ユニット列挙を修正：正確な GameCore の Unit / City 共通ルックアップは、どちらも `collection + 0x98 / +0xA0` の chunk ポインタ範囲を使用します。v0.2.0 の Units 用 `+0x08 / +0x10` は無効なユニットアドレスを生成していました。
- 継続適用を機能単位で分離し、1つの実験機能の失敗が他の有効機能をまとめて実行エラーにしないよう変更しました。
- 機能を有効状態にする前に、その機能だけを一度適用して検証します。初回失敗時は継続ループへ入りません。
- GameCore リモート呼び出しブリッジを必要な機能だけで生成します。Gold / Faith、ユニット HP / 移動、人口、一部 AI 機能は不要なリモートスレッド呼び出しに依存しません。
- 失敗した機能だけを継続適用から外し、個別のエラー状態を保持します。他機能には影響しません。

## 受け入れテスト

まず Num 6、Num 7、Num .、PageDown、Alt+Num 1、Alt+Num 2、Alt+Num 5、Alt+Num 6、Alt+Num 7 を再確認してください。研究・社会制度・生産・資源系は、今回得られる実機エラー情報に基づき引き続き校正します。

Civilization VI のシングルプレイヤー専用です。現在の正確な Profile は Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) のみに限定されます。
