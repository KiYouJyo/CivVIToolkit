# CivVIToolkit v0.2.2 Preview

本版本修复了在真实单机对局中出现 `The game root pointer is null.` 后导致全部修改器项目进入“运行错误”的问题。

## 修复

- 不再把 GameContext 根指针作为唯一的本地玩家解析入口。
- 优先继续使用已经验证过的 GameContext → LocalPlayerId 路径。
- 当 Civilization VI 在运行过程中暂时清空 GameContext 根指针时，使用已经在该精确 Build 上验证过的 `Player::Manager` 单机玩家槽位 0 回退路径。
- 回退前会验证玩家槽位处于活动状态，并验证 Treasury、Religion、Influence 三个 live component 指针均存在；验证失败则拒绝继续写入。
- 保留 13 个 AoB 锚点和 GameCore SHA-256 锁定，不放宽版本安全门。

## 验收重点

进入 Gathering Storm 单机对局后，修改器页面不应再因为 `game root pointer is null` 全部显示运行错误。优先验收 Num 1、Num 2、Num 5、PageUp，再继续验收单位、城市、研究、市政、生产与 AI 功能。
