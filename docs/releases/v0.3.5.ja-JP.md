# CivVIToolkit v0.3.5 Preview

## 修正
- Trainer リストを安定した ViewModel に変更しました。22 項目は一度だけ生成され、バックグラウンド監視では `INotifyPropertyChanged` によるプロパティ更新だけを行い、`ItemsSource` を定期的に再設定しません。
- メイン Trainer とコンパクト Trainer は同じ安定した項目インスタンスを共有し、コンパクトウィンドウも状態更新時にリストを再バインドしません。
- 「影響力を追加」と「ゴールドを追加」に明示的な「適用」ボタンを追加しました。入力後にボタンで実行でき、既存のグローバルショートカットも現在の入力値を使用します。
- v0.3.4 のプロセス / GameCore ポーリングのデバウンス処理も維持します。

## 維持
- 22 項目のシングルプレイ Trainer、安定性スケジューラ、グローバルショートカット。
- Steam / DX12 / Gathering Storm 1023995 の厳密 SHA + 13 AoB fail-closed 検証。
- v0.3.3 の高 DPI / コンパクトウィンドウ配置修正。
