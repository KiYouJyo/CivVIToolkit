This version establishes CivVIToolkit's first installable distribution foundation.

- Automatically detects Steam / Epic Games installations.
- Automatically identifies Civilization VI DX11 / DX12 runtime processes.
- Provides read-only Runtime Diagnostics for future stable Signature Profiles.
- Establishes the classic 22-feature single-player Trainer catalog with safety gating; unverified memory signatures remain disabled.
- Reserves module boundaries for save management, map/game information, Mod management, and quick launch.
- Provides Simplified Chinese, Japanese, and English UI resources.
- Moves acceptance and release distribution to a signed x64 MSIX instead of an unpackaged WinUI 3 executable.
- Adds a one-click installation ZIP, signature verification, and SHA-256 checksums.

> This is still a Preview. Trainer features are intended for local Civilization VI single-player use only.
