# CivVIToolkit v0.3.4 Preview

## Fixed
- Fixed the Trainer rows periodically jumping / visibly rebuilding after Civilization VI starts.
- Process polling now debounces transient module-enumeration failures: once Gathering Storm GameCore has been confirmed for the same game PID, a single short-lived read failure no longer immediately marks it as unloaded.
- A confirmed session is retained for up to two polling intervals across transient process-probe misses, while a genuinely exited game still detaches normally.
- This prevents the 2-second monitor from repeatedly retriggering Trainer attach/detach, clearing the UI signature, and rebuilding the feature list.
