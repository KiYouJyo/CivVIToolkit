# CivVIToolkit v0.2.4

このリリースでは、Trainer の受け入れテスト体験をさらに改善し、ショートカット表示の揺れと数値アクションの設定性を修正します。

## 変更点

- ショートカット表示のサイズと位置を固定し、ポーリング更新時の揺れを防止。
- 表示状態が実際に変化した場合のみ Trainer リストを再生成し、プロセス監視ごとの ListView 再構築を停止。
- 「ゴールドを追加」と「影響力を追加」に数値入力欄を追加。
- 入力値は現在の実行中に保持され、行クリックとグローバルホットキーの両方で使用。
- 1～8,000,000 の正整数を入力可能とし、fixed-point のオーバーフロー検証も継続。
- アプリが実際に使用する Trainer Engine を、v0.2.3 で追加した安定性スケジューラへ切り替え。

## 受け入れ確認

1. Trainer 画面を数分表示し、ショートカット表示がバックグラウンド確認で動かないことを確認。
2. ゴールド／影響力の入力値を変更し、行クリックとホットキーの両方で実行。
3. 複数の継続機能を同時に有効化し、v0.2.3 の安定性スケジューラを引き続き確認。
