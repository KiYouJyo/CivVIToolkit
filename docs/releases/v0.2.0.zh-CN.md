v0.2.0 Preview 是 CivVIToolkit 首个完整 22 项修改器验收版本。

- 针对 Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` 精确 GameCore Profile，将经典 22 项单机功能全部接入可操作状态；
- 22 个功能均支持原快捷键，同时可直接点击修改器列表中的对应功能行；
- 无限金钱、无限信仰、影响力、单位移动/生命、建造者次数、城市人口与资源库存使用已确认的 live Player 数据链；
- 研究、市政与城市生产使用精确 Build 的 GameCore 原生函数，通过短生命周期 x64 调用桥执行，不注入常驻 DLL；
- 单位随时升级采用精确原字节验证的可逆 Patch，并在关闭功能、Detach 或正常退出时恢复；
- AI 金钱、信仰、研究、市政、影响力、移动、生产与资源控制已接入非本地玩家枚举；
- 三语界面新增“可启用 / 已启用 / 可执行 / 实验性验收”等实时状态。

### 已完成实机验证

- Steam / DX12 / Gathering Storm 1023995 GameCore 指纹与 13 个 AoB anchor；
- Local Player、Treasury、Religion、Influence 数据链；
- Gold / Faith 与游戏 UI 数值一致；
- `PageUp` 增加金钱 +10,000 已在真实单机对局中确认有效。

### 本轮验收重点

其余 21 项已经完成实现，但仍需要真实游戏逐组验收。建议使用可回滚的单机存档，并按以下顺序测试：

1. Num 1 / Num 2 / Num 5 / Num 9 / PageUp：资源与余额；
2. Num 3 / Num 4 / Num 8：研究、市政、生产；
3. Num 6 / Num 7 / Num 0 / Num . / PageDown：本地单位与城市；
4. Alt+Num 1–9：AI 与战斗。

`Num 0 单位随时升级`、`Alt+Num 7 一击必杀`、`Alt+Num 8 AI 无法完成建造 / 招募` 当前标记为“实验性验收”，需要重点检查不同游戏状态下的边界行为。

> 当前仍为 Preview。修改器仅用于 Civilization VI 本地单机模式；不包含多人联机作弊或反作弊规避。
