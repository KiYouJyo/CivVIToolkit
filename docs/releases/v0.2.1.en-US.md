# CivVIToolkit v0.2.1 Preview

This build structurally fixes the generic runtime failures observed during the first complete 22-feature v0.2.0 acceptance pass.

## Fixes

- Correct unit enumeration: the exact GameCore Unit / City shared lookup uses the chunk pointer range at `collection + 0x98 / +0xA0` for both collections. v0.2.0 incorrectly used `+0x08 / +0x10` for Units, producing invalid unit addresses.
- Isolate continuous enforcement per feature so one experimental failure no longer marks unrelated enabled features as runtime errors.
- Apply each toggle once before it is considered enabled; an initial failure does not enter the enforcement loop.
- Create the remote GameCore call bridge only for features that actually require it. Gold/Faith, unit HP/movement, population and several AI paths no longer depend on an unnecessary remote-thread capability.
- Remove only the failing feature from continuous enforcement and retain its own error state so it can be retried without affecting other features.

## Acceptance focus

Re-test Num 6, Num 7, Num ., PageDown, Alt+Num 1, Alt+Num 2, Alt+Num 5, Alt+Num 6 and Alt+Num 7 first. Research, civics, production and resource paths still need calibration from the exact live error details produced by this pass.

Single-player Civilization VI only. The exact profile remains limited to Steam / DX12 / Gathering Storm 1.0.12.68 (1023995).
