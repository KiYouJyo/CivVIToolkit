# CivVIToolkit v0.3.4 Preview

## 修正
- Civilization VI 起動後に Trainer の項目が一定間隔で跳ねる / 再描画される問題を修正しました。
- 同一ゲーム PID で一度確認済みの Gathering Storm GameCore は、一時的なモジュール列挙失敗だけでは即座に未ロード扱いにしません。
- 一時的なプロセス検出失敗は最大 2 回のポーリング期間だけ安定済みセッションを保持し、ゲームが実際に終了した場合は通常どおり切断します。
- これにより 2 秒ごとの監視で不要な Trainer Attach / Detach と UI リスト再構築が発生するのを抑止します。

## 維持
- v0.3.3 のメイン Trainer / コンパクト Trainer の重なり修正。
- 22 項目、グローバルショートカット、安定性スケジューラ、Gold / Influence 入力値。
- Steam / DX12 / Gathering Storm 1023995 の厳密 SHA + 13 AoB fail-closed 検証。
- 中国語 / 日本語 / 英語の即時切り替え。
