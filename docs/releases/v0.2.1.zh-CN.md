# CivVIToolkit v0.2.1 Preview

本版本针对 v0.2.0 首轮 22 项集中验收中出现的“运行错误”进行结构性修复。

## 修复

- 修正单位集合枚举：精确 GameCore 的 Unit / City 通用查找器均使用 `collection + 0x98 / +0xA0` 的 chunk 指针范围；v0.2.0 对 Units 使用的 `+0x08 / +0x10` 会产生无效单位地址。
- 修改器持续执行改为逐功能隔离；一个实验功能失败不再把其它已启用功能一起标记为运行错误。
- 启用功能前先单独执行一次，首次执行失败时不会进入持续循环。
- 远程 GameCore 调用桥改为按需创建；金币、信仰、单位生命/移动、人口和部分 AI 功能不再无条件依赖远程线程调用。
- 失败功能自动退出持续执行并保留自己的错误状态，可再次点击重试，不影响其它功能。

## 验收重点

优先重新验证 Num 6、Num 7、Num .、PageDown、Alt+Num 1、Alt+Num 2、Alt+Num 5、Alt+Num 6、Alt+Num 7。研究、市政、生产和资源类仍需根据本轮真实错误信息继续校准。

仅用于 Civilization VI 单机游戏。当前精确 Profile 仍限定 Steam / DX12 / Gathering Storm 1.0.12.68 (1023995)。
