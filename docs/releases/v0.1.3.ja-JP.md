v0.1.3 Preview では、実機 Build で検証済みの最初の書き込み機能を有効化します。

- Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` を厳密な GameCore SHA-256 で引き続き限定；
- Gold / Faith の読み取り値が実ゲーム UI と一致することを確認；
- `PageUp` またはボタンで実行する「ゴールド +10,000」を追加；
- 各書き込み前に GameCore fingerprint、13 個の AoB anchor、ローカルプレイヤー、Treasury パスを含む完全な読み取り専用 Profile 検証を再実行；
- Gold はゲーム本来の 1/256 固定小数点形式で書き込み、直後に再読み取りして検証；
- 残り 21 項目は Signature Pending のままで、未検証アドレスへの書き込みは行いません。

> 現在も Preview です。Trainer は Civilization VI のローカル・シングルプレイ専用です。
