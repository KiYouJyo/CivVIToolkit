# CivVIToolkit v0.3.2 Preview

本次验收版本集中修复 v0.3.1 实机测试中暴露的三个问题。

## 修改器连接

- 修复 Gathering Storm 对局初始化阶段 `Player::Manager` 暂时为空后，修改器永久停留在“运行错误”的问题。
- 当游戏进程和 GameCore 已加载、但 Trainer 尚未就绪时，会自动重试精确 Profile 连接。
- 保留 Steam / DX12 / Gathering Storm 1.0.12.68 (1023995) 的精确 GameCore SHA-256、13 项 AoB 与指针链 fail-closed 校验；未通过校验的构建仍拒绝写入。

## UI 与高 DPI

- 修改器分类改为顶部横向分类栏，让功能列表占用完整内容宽度。
- 收紧主修改器功能行列宽，修复 NumberBox、ToggleSwitch 与状态文本互相遮挡。
- 紧凑窗口按 `XamlRoot.RasterizationScale` 将逻辑尺寸换算为物理像素，修复 150%/200% 等缩放下窗口实际过窄的问题。
- 紧凑窗口精简为功能名 / 状态、快捷键、操作控件三列，提高高 DPI 和窄窗口可用性。

## 即时语言切换

- 语言选择现在会立即更新 MRT Core 语言、当前 Culture、ResourceLoader 和已打开界面，无需重启应用。
- 主窗口、导航、首页、修改器、诊断、设置和紧凑修改器均加入运行时本地化刷新。
- 修复语言切换提示显示 `!Settings_RestartInfo...!` 占位符的问题。

本版本仍为 Preview 验收构建，GitHub 正式发布保持关闭。
