CivVIToolkit v0.3.0 Preview completes the first high-fidelity Figma-to-WinUI 3 UI pass and wires the toolkit's existing runtime capabilities into the redesigned shell.

- Rebuilt the main window around the Figma v2 light WinUI layout: 48 px title bar, 220 px collapsible navigation pane, light canvas, white cards, and blue accents.
- Wired Steam / Epic Games discovery, DX11 / DX12 detection, PID, version, executable path, rescan, and quick launch into Home.
- Organized the first 22 Trainer entries into Resources & Economy, Science & Culture, Units & Combat, and Cities & Production, with category filtering and search.
- Added an always-on-top compact Trainer window for quick in-game access to the 22 entries.
- Preserved user-triggered read-only runtime diagnostics under Presets & Diagnostics.
- Preserved language preference and version information under Settings & About.
- Save Manager, Mod Manager, and Encyclopedia remain intentional empty entrances until their later milestones; the UI does not invent unavailable data.
- Trainer writes remain disabled until runtime signature validation is completed; no guessed addresses are used to modify the game process.
- Aligned app, MSIX Package Version, and release metadata to 0.3.0 / 0.3.0.0.

> This is still a Preview build. The Trainer is intended for local Civilization VI single-player use only.
