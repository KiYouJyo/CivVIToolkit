# CivVIToolkit v0.3.1 Preview

- 参考 UrbanPlanToolbox 的实际 WinUI 3 壳层，改用原生 `TitleBar`、`NavigationView`、Mica 与系统主题资源，修复此前自绘导航在动画、选中反馈和材质上的割裂感。
- 取消首页、诊断、设置等页面的固定最大宽度，最大化窗口时卡片会使用可用空间；中窄窗口自动重排首页控制卡、模块卡、诊断卡和语言设置。
- 首页继续保留 Steam / Epic、DX11 / DX12 检测与快捷启动；存档、Mod、百科仅保留空入口。
- 将已经实机验证的 Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` Trainer Profile 接回新版 UI。
- 恢复 22 项修改器、全局快捷键、稳定性错峰调度、金钱/影响力自定义输入以及置顶紧凑修改器窗口。
- 不匹配的游戏版本继续采用 fail-closed 策略，GameCore SHA 与 13 个 AoB 校验失败时拒绝写入。

> 当前仍为 Preview，修改器仅面向 Civilization VI 本地单机模式。
