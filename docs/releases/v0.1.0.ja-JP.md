このバージョンでは、CivVIToolkit の最初のインストール可能な配布基盤を整備しました。

- Steam / Epic Games のインストール元を自動検出；
- Civilization VI の DX11 / DX12 実行プロセスを自動判定；
- 将来の安定した Signature Profile 作成に使用する読み取り専用 Runtime Diagnostics；
- クラシック 22 項目のシングルプレイ Trainer カタログと安全な gating を実装し、未検証のメモリシグネチャはまだ有効化しない；
- セーブ管理、マップ／ゲーム情報、Mod 管理、クイック起動のモジュール境界を予約；
- 简体中文、日本語、English の 3 言語 UI；
- 展開済み WinUI 3 実行ファイルではなく、署名済み x64 MSIX に移行；
- ワンクリック導入 ZIP、署名検証、SHA-256 チェックサムを追加。

> 現在は Preview です。Trainer は Civilization VI のローカル・シングルプレイ専用です。
