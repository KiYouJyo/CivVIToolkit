# CivVIToolkit v0.3.4 Preview

## 修复
- 修复 Civilization VI 启动后修改器选项周期性“跳动/闪一下”的问题。
- 进程轮询现在会对短暂的进程模块枚举失败做去抖：同一游戏 PID 下，已确认加载的 Gathering Storm GameCore 不会因为一次短暂读取失败就立刻被判定为卸载。
- 对短暂的进程探测失败保留最多两个轮询周期的已确认会话；真正退出游戏后仍会自动断开。
- 这样可避免每 2 秒轮询时重复触发 Trainer Attach / Detach、清空 UI 签名并重建功能列表。

## 保留
- v0.3.3 的主修改器和紧凑窗口遮挡修复。
- 22 项单机修改器、全局快捷键、稳定性调度器、金钱/影响力输入值。
- 精确 Steam / DX12 / Gathering Storm 1023995 SHA + 13 AoB fail-closed 校验。
- 中 / 日 / 英即时语言切换。
