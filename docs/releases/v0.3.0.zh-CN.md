CivVIToolkit v0.3.0 Preview 完成第一轮 Figma → WinUI 3 高保真界面收束，并把已经具备的运行时能力接入新界面：

- 主窗口切换为 Figma v2 的浅色 WinUI 风格：48 px 标题栏、220 px 可折叠侧栏、浅灰内容画布、白色卡片与蓝色强调色；
- 首页接入 Steam / Epic Games 安装识别、DX11 / DX12、PID、版本、路径、重新扫描与快捷启动；
- 修改器按「资源与经济 / 科技与文化 / 单位与战斗 / 城市与建造」自动整理第一版 22 项功能，并支持分类与搜索；
- 新增置顶紧凑修改器窗口，便于游戏过程中快速查看与操作 22 项功能；
- 预设与诊断页继续提供用户主动触发的只读运行时诊断；
- 设置与关于页保留语言偏好及版本信息；
- 存档管理、Mod 管理、百科按当前产品计划只保留入口，不制造尚未实现的数据与功能；
- 未完成运行时签名验收的 Trainer 写入仍保持禁用，不使用猜测地址修改游戏进程；
- 同步应用版本、MSIX Package Version 与发布元数据为 0.3.0 / 0.3.0.0。

> 当前仍为 Preview。Trainer 仅面向 Civilization VI 本地单人游戏。
