v0.1.2 Preview は、2 回目の実機検証で判明した live Player のリソース・オブジェクトチェーンを修正します。

- Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` の厳密な GameCore Profile を維持；
- `Player::Manager` が返すのは live `Player::Instance` であり、`Player::Cache::Instance` ではないことを確認；
- `Player + 0xB0` の Cache component block を live Player に対して誤って読む処理を削除；
- ゲーム自身の bridge コードに基づき、live Player から Religion `+0x720`、Influence `+0x748`、Treasury `+0x780` の各ポインターを直接取得；
- live Faith / Gold / Influence bridge の AoB 検証を追加し、direct-component path も実行時シグネチャで認証；
- 診断 JSON には Gold / Faith / Influence の raw fixed-point 値と実際の component address を引き続き出力；
- v0.1.2 でも Trainer の書き込みは無効のままで、ゲーム UI と読み取り値が一致した後にのみ実際の変更を有効化します。

> 現在も Preview です。Trainer は Civilization VI のローカル・シングルプレイ専用です。
