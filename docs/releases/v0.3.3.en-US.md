# CivVIToolkit v0.3.3 Preview

This build continues the UI cleanup after v0.3.2 acceptance, focusing on the remaining Trainer control overlap.

## Fixed
- Constrains the WinUI `ToggleSwitch` layout footprint so the default template cannot overflow underneath the shortcut chip.
- Applies the same constrained native ToggleSwitch layout to both the main and compact Trainer UIs.
- Reflows compact Trainer rows into two tiers, separating feature/status text from shortcut/action controls to remove horizontal collisions.
- Increases the compact window logical width to 580 DIPs while continuing to translate it through `RasterizationScale` for 150% / 200% Windows scaling.
- Keeps Gold and Influence NumberBoxes in a dedicated action area instead of sharing space with switches or shortcut chips.

## Unchanged
- Exact Steam / DX12 / Gathering Storm 1023995 profile and fail-closed checks remain unchanged.
- All 22 Trainer features, global shortcuts, stability scheduler, and live language switching remain enabled.
- Save Manager, Mod Manager, and Encyclopedia remain placeholder entrances only.
