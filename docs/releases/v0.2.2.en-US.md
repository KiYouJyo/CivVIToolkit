# CivVIToolkit v0.2.2 Preview

This preview fixes the live single-player failure where `The game root pointer is null.` caused the Trainer page to fall into runtime errors.

## Fixes

- The GameContext root pointer is no longer the only route used to resolve the local player.
- The already verified GameContext → LocalPlayerId route remains the preferred path when available.
- If Civilization VI temporarily clears the GameContext root while a match is still live, the exact-build profile falls back to the previously verified `Player::Manager` single-player slot 0 route.
- Before accepting the fallback, the profile verifies that the slot is active and that the live Treasury, Religion, and Influence component pointers are all present. If validation fails, writes remain blocked.
- The 13 AoB anchors and GameCore SHA-256 lock remain mandatory; no build-safety gate is relaxed.

## Acceptance focus

After entering a Gathering Storm single-player match, the Trainer should no longer show runtime errors solely because the game root pointer is null. Recheck Num 1, Num 2, Num 5 and PageUp first, then continue with unit, city, research, civic, production, and AI features.
