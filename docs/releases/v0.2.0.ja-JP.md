v0.2.0 Preview は、CivVIToolkit で初めて 22 項目すべてを実装した Trainer 受け入れテスト版です。

- Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` の厳密な GameCore Profile 向けに、クラシックな 22 項目すべてを操作可能にしました；
- 全 22 項目で従来のホットキーを使用でき、Trainer リストの行をクリックして実行 / 切り替えることもできます；
- ゴールド、信仰力、影響力、移動力、体力、労働者使用回数、人口、資源在庫は検証済みの live Player オブジェクト経路を使用します；
- 研究、社会制度、都市生産は厳密 Build の GameCore 関数を短寿命の x64 呼び出しブリッジから実行し、常駐 DLL は注入しません；
- 「常にアップグレード可能」は元バイトを確認する可逆 Patch を使用し、無効化 / Detach / 正常終了時に元へ戻します；
- AI のゴールド、信仰力、研究、社会制度、影響力、移動、生産、資源制御を非ローカルプレイヤー列挙に接続しました；
- 中国語 / 日本語 / 英語 UI に Ready / Enabled / Action ready / Experimental acceptance などの動的状態を追加しました。

### 実機検証済み

- Steam / DX12 / Gathering Storm 1023995 の GameCore fingerprint と 13 個の AoB anchor；
- Local Player、Treasury、Religion、Influence の実行時経路；
- Gold / Faith の値が実ゲーム UI と一致；
- `PageUp` のゴールド +10,000 が実際のシングルプレイヤー対局で動作することを確認済みです。

### 今回の受け入れテスト

残り 21 項目は実装済みですが、実ゲームでのグループ別検証が必要です。戻せるシングルプレイヤーセーブを使用し、次の順で試すことを推奨します。

1. Num 1 / Num 2 / Num 5 / Num 9 / PageUp：残高・資源；
2. Num 3 / Num 4 / Num 8：研究・社会制度・生産；
3. Num 6 / Num 7 / Num 0 / Num . / PageDown：ローカルユニット・都市；
4. Alt+Num 1–9：AI・戦闘。

`Num 0 常にアップグレード可能`、`Alt+Num 7 一撃必殺`、`Alt+Num 8 AI 生産停止` は現在「実験的検証」として表示し、ゲーム状態による境界挙動を重点的に確認します。
