# CivVIToolkit v0.3.3 Preview

v0.3.2 の実機検証で残っていた Trainer コントロールの重なりを重点的に修正しました。

## 修正
- WinUI `ToggleSwitch` のレイアウト幅を明示し、ショートカット領域へのテンプレートのはみ出しを防止。
- メイン Trainer とコンパクト Trainer で同じ制約付きネイティブ ToggleSwitch レイアウトを使用。
- コンパクト Trainer の行を二段構成に変更し、機能名/状態とショートカット/操作コントロールを分離。
- コンパクトウィンドウの論理幅を 580 DIP に拡大し、`RasterizationScale` による物理ピクセル変換を維持して 150% / 200% スケーリングに対応。
- ゴールド/影響力の NumberBox を独立した操作領域に配置し、スイッチやショートカットとの重なりを防止。

## 維持される内容
- Steam / DX12 / Gathering Storm 1023995 の厳密 Profile と fail-closed 検証は変更なし。
- 22 項目、グローバルショートカット、安定化スケジューラ、即時言語切替は継続。
- セーブ管理、Mod 管理、百科は引き続き入口のみです。
