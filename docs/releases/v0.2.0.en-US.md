v0.2.0 Preview is the first CivVIToolkit acceptance build with all 22 classic trainer entries implemented.

- implement all 22 single-player trainer entries for the exact Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)` GameCore profile;
- keep every original hotkey and make every trainer row directly clickable;
- use the verified live Player object graph for Gold, Faith, Influence, unit movement/health, builder charges, city population and resource stockpiles;
- use exact-build GameCore routines for research, civics and city production through a short-lived x64 call bridge, with no persistent injected DLL;
- use original-byte-checked reversible patches for the always-upgrade toggle, restoring them on disable, detach or normal shutdown;
- wire AI Gold, Faith, research, civics, Influence, movement, production and resource controls through non-local player enumeration;
- add live Ready / Enabled / Action ready / Experimental acceptance states to the Chinese, Japanese and English UI.

### Live validation already completed

- Steam / DX12 / Gathering Storm 1023995 GameCore fingerprint and all 13 runtime AoB anchors;
- Local Player, Treasury, Religion and Influence runtime paths;
- Gold / Faith readings match the actual game UI;
- `PageUp` Add Gold +10,000 has been confirmed working in a real single-player match.

### v0.2.0 acceptance focus

The remaining 21 entries are implemented but still require grouped live gameplay acceptance. Use a disposable/recoverable single-player save and test in this order:

1. Num 1 / Num 2 / Num 5 / Num 9 / PageUp: balances and resources;
2. Num 3 / Num 4 / Num 8: research, civics and production;
3. Num 6 / Num 7 / Num 0 / Num . / PageDown: local units and cities;
4. Alt+Num 1–9: AI and combat behavior.

`Num 0 Units Can Always Upgrade`, `Alt+Num 7 One-Hit Kill`, and `Alt+Num 8 AI Cannot Complete Production` are currently marked **Experimental acceptance** because their gameplay semantics have more state-dependent edge cases and need focused validation.

> This is still a Preview build. Trainer functionality is intended only for local Civilization VI single-player use and does not include multiplayer cheating or anti-cheat bypass behavior.
