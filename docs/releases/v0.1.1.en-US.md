v0.1.1 Preview focuses on validating the first real Civilization VI Trainer build profile.

- add the first exact GameCore profile for Steam / DX12 / Gathering Storm `1.0.12.68 (1023995)`;
- strictly bind support to the verified GameCore SHA-256;
- add runtime GameCore AoB validation and a read-only local-player resource probe;
- fix the incorrect Player Manager singleton and active-player slot chain discovered during the first live acceptance test;
- validate the Game Context current-game getter, the correct Player Manager getter, and ten runtime signature anchors;
- include raw Gold / Faith / Influence fixed-point values plus Manager / Player / Component addresses in diagnostics for traceability;
- keep Trainer writes disabled until the read chain and signatures are fully validated on the real game build.

> This is still a Preview build. Trainer functionality is intended only for local Civilization VI single-player use.
